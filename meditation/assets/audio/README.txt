SoulSpace Audio Directory
===========================

To use your local MP3 file:
1. Download the MP3 track "Spa Ambient (10min)" by Rockot from Pixabay:
   https://pixabay.com/music/ambient-spa-ambient-10min-253179/
2. Save it into this folder with the name:
   spa-ambient-10min.mp3
   (or gentle-ambient.mp3)

Note: Even without an MP3 file placed here, SoulSpace includes an automatic built-in Web Audio ambient sound synthesizer (peaceful 432Hz harmonic drone) that plays when the sound toggle is turned ON!
